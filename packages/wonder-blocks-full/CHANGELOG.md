# @osati-ai/wonder-blocks-full

## 1.0.0

### Major Changes

- Initial release of Wonder Blocks Full - the complete umbrella package for all Wonder Blocks components
- **Private GitHub Packages Distribution**: Securely published to GitHub Packages with restricted access
- Provides a single installation point for all Wonder Blocks packages
- Includes both direct exports for commonly used components and namespaced exports for better organization
- Supports tree-shaking for optimal bundle sizes
- Full TypeScript support with re-exported types from all subpackages

### Features

- **Complete Component Library**: Includes all 30+ Wonder Blocks packages
- **Convenient Imports**: Import commonly used components directly from the main entry point
- **Namespaced Exports**: Access less common components via organized namespaces (e.g., `Accordion`, `Modal`)
- **Tree-shaking Support**: Only bundles the components you actually use
- **TypeScript First**: Full type definitions for all components and utilities
- **React 19 Compatible**: Updated for the latest React version

### Included Packages

- Core: `wonder-blocks-core`, `wonder-blocks-button`, `wonder-blocks-typography`
- Layout: `wonder-blocks-layout`, `wonder-blocks-grid`
- Form: `wonder-blocks-form`, `wonder-blocks-labeled-field`, `wonder-blocks-search-field`
- Navigation: `wonder-blocks-breadcrumbs`, `wonder-blocks-tabs`, `wonder-blocks-dropdown`
- Display: `wonder-blocks-modal`, `wonder-blocks-popover`, `wonder-blocks-tooltip`
- And many more...

See the README for complete usage examples and migration guide.
